# API Documentation

Open Karaoke Studio provides a REST API for programmatic access to all functionality.

## Quick Start

### Base URL

```
http://localhost:5123/api
```

### Content Type

All API endpoints accept and return `application/json` unless otherwise specified (audio and image endpoints return binary data).

### Interactive Reference

The complete, always-current API reference is auto-generated by FastAPI — see the [API Reference](/api-reference) page for Swagger UI and ReDoc URLs.

## Integration Examples

### Basic Song Processing

```bash
# Import from YouTube (downloads and starts vocal separation)
curl -X POST http://localhost:5123/api/youtube/download \
  -H "Content-Type: application/json" \
  -d '{"video_id": "VIDEO_ID", "title": "Song Title", "artist": "Artist Name"}'

# Check processing status
curl http://localhost:5123/api/jobs/status

# Download results
curl http://localhost:5123/api/songs/{id}/download/instrumental
```
